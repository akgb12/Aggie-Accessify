# Quote check

You check whether pieces of text are written in an image from a lecture slide.

For each quote, answer written: true only if that text appears in the image as written words, symbols or code. Ignore differences in letter case, punctuation, spacing and line breaks, and treat a math symbol and its spoken name as the same (μ and mu, x₁ and x sub 1). Answer false if the text is not in the image, or is only implied by it.

Judge only from the image. Return one result per quote, in the order given, and only the fields required by the provided output schema.
