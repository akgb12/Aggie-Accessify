# Text inventory

Transcribe the text that is visibly written in this image: words, numbers, symbols, code and labels, including text inside photos, screenshots, charts and diagrams.

Write each separate piece of text (a line, a label, a caption) as one item, in reading order, exactly as written. Keep its spelling, letter case and symbols. Write math symbols as they appear (μ, σ², x₁).

Do not describe the image, guess hidden or cut-off words, translate, or add text that is not drawn. If part of a word is cut off at the edge, write only the visible part. If no text is visible, return an empty list.

Return only the fields required by the provided output schema.
